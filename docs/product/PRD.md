## 1. 产品命题

CyberKindred 是面向 Windows 的 AI 陪伴电台：它以音乐为主要媒介，逐步了解使用者，在合适的时间提供克制、持续且可控的陪伴。产品价值不是“比播放器更会播放”，而是把用户拥有或正在收听的音乐、当下情境与可纠正的长期了解组织成一段像熟悉朋友主持的个人节目。

产品明确承认自己是 AI。它不冒充真人、恋人、治疗师或权威，不把持续参与设计成情感依赖，也不以收集更多私人信息作为体验前提。

## 2. 目标用户与问题

首发服务于在个人 Windows 电脑上长时间工作、学习或独处，已有本地音乐或 Apple Music 使用习惯，并愿意自行配置 OpenAI API Key 的少量中文内测用户。

他们目前面临的核心问题是：传统播放器理解曲目但不了解生活节奏；通用聊天助手了解对话却没有稳定的音乐陪伴节奏；自动推荐缺少透明反馈与可控记忆。CyberKindred 将这三者连接起来，同时让用户始终知道系统记住了什么、为何说这句话、何时会发声以及如何停止。

## 3. 产品原则

1. **音乐先于聊天**：音乐保持连续，AI 主播只在开场和有意义的间隔出现。
2. **了解必须可见**：长期记忆必须能查看、纠正、停用和删除；推断先成为提案，不直接成为事实。
3. **主动但不惊扰**：日程到点只通知，用户确认后才开播；不在后台突然发声。
4. **来源诚实**：本地曲库支持精确队列；Apple Music 首发只做 Windows 系统媒体会话陪伴控制，不虚构远程选曲能力。
5. **本地优先、最少外发**：资料与记忆以本机保存为主；每个外部服务的数据用途都可解释。
6. **降级仍可用**：联网 AI、天气或元数据失败时，本地音乐与用户数据管理继续工作。
7. **审美服务于安静陪伴**：使用简体中文、OLED 深色、Nothing-inspired 的高对比工业界面，避免喧闹装饰。

## 4. 首发产品范围

Documentation Baseline v1 约束一个 Windows 10 22H2 / Windows 11 x64 可安装内测版。首发闭环包括：

- 首次引导，完成音乐来源、OpenAI BYOK、声音、初始画像、手动城市、日程与隐私选择。
- 本地曲库扫描、联网 MusicBrainz 元数据补全、真实候选集选曲与精确队列播放。
- Apple Music Windows App 的 GSMTC 会话发现、当前曲目读取及会话能力允许的播放控制，并围绕实际播放内容串场。
- 节目开场、每 2–3 首歌曲一次的默认串场、TTS 输出、文字输入与反馈闭环。
- 画像、记忆提案、已批准记忆、长期摘要与 30 天原始对话生命周期。
- 基于当地时间、用户日程和手动城市天气的情境；日程通知需确认后开播。
- 本地数据查看、编辑、导出、删除与全部重置，以及可理解的联网/离线降级状态。

详细行为只由 `FRS.md`、`AI-BEHAVIOR.md` 与 `UX-SPEC.md` 定义；本节不作为单项验收清单。

## 5. 明确非目标

首发不包含：macOS/Linux/移动端、完整 Apple Music MusicKit、Apple Music Web DOM 自动化、网易云或 Spotify 接入、语音输入、屏幕/前台应用/麦克风采集、设备自动定位、账号后端或跨设备同步、公开社区、广告、遥测、自动更新、公开商店发布、正式代码签名、歌词抓取以及未经用户确认的自动发声。

产品不保证播放受 DRM 保护的远程音频文件，不绕过平台订阅、版权或地区限制，不将 Apple Music 陪伴模式描述为“AI 可以任意点播 Apple Music”。

## 6. 成功定义

### 6.1 用户成功

- 新用户无需开发者协助即可完成安装、引导、导入本地曲库并启动首个节目。
- 用户可连续收听至少 30 分钟，音乐不中断于非必要的 AI 交互，且能理解每个主要控制的当前状态。
- 用户能准确说出系统长期记住的内容，并能在一个页面内纠正或删除任一记忆。
- Apple Music 用户能区分“陪伴控制”与“精确点歌”，且 UI 不展示当前会话不支持的动作。
- 到点提醒不会造成意外出声；确认、忽略和稍后处理都具有明确结果。

### 6.2 内测质量指标

- 至少 90% 的引导尝试在无需重启应用的情况下完成。
- 至少 95% 的正常关闭节目留下完整运行记录，崩溃或断电后的下一次启动可恢复到安全的非自动播放状态。
- 内测反馈中，“串场太频繁”的比例低于 20%，且用户可通过“少说一点”即时降低频率。
- 所有首发需求都映射到架构组件、测试场景与原子开发任务；发布候选不存在未解释的高风险项。
- 密钥、原始对话和本地绝对音乐路径不出现在应用日志或提交制品中。

精确性能、安全、隐私和兼容性判定由 `NFRS.md` 定义。

## 7. 发布与商业假设

- 首发面向本人及少量受邀内测用户，免费、非商业、手工分发。
- 使用者自行承担 OpenAI API 费用，并拥有本地音乐的合法使用权及有效 Apple Music 订阅（如使用该模式）。
- 当前不依赖 Apple Developer Program，因此完整 MusicKit 不进入首发。
- 公开或商业发布前必须重新审查代码签名、安装信誉、隐私政策、第三方服务条款、字体与依赖许可证。

## 8. 产品决策边界

以下变化视为范围变更，必须先更新本 PRD 并经用户批准：增加采集通道、改变记忆/原文保留语义、接入新的付费或账号服务、允许未确认自动发声、承诺远程精确点歌、公开发布或将产品关系定位改为恋爱/治疗陪伴。
