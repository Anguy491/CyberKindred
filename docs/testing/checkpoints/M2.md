## Actual failures and blockers

1. `RISK-016`: `DATA-MODEL.md` says origin switch deletes the old credential, while `PRIVACY-DATA-LIFECYCLE.md` says each origin credential remains until API-005/full reset. The related API-004 implementation and commit are frozen pending Product Owner semantics.
2. `RISK-017`: EVT-008/009 claim delivery exactly once, but the current `emit → mark delivered` outbox has an unavoidable crash replay window without durable consumer acknowledgement. The implementation proves exactly one authoritative terminal and at-least-once transport, not the public claim.
3. `RISK-018`: model settings must pass capability probe before save, but API-006 only tests the already-saved model and API-008 has a 5-second settings contract. The authority must choose the user-visible flow before implementation.
