## Completed scope

- `TASK-004`–`TASK-010` are `Done`: pinned Tauri/React/Rust shell, dual-language schema validation, strict IPC/errors/events, SQLite repositories and retention, Windows Credential Manager boundary, diagnostics, provider configuration and onboarding.
- The three authorized provider decisions are implemented: API-004 retains credentials per canonical origin until exact API-005/full reset; API-009 has one authoritative terminal with at-least-once transport and frontend `operationId` dedupe; an actual API-008 model change uses the 60-second pre-save capability probe and atomic patch.
- API-002/API-003 persist an exact, revisioned seven-step prefix. Profile, narration density and settings revision update atomically; invalid transitions, corrupt/future state and JavaScript unsafe revisions fail closed.
- API-010–API-012 use a native picker-only path boundary, path-free DTOs, canonical identity, revision CAS, reparse/ancestor-redirection checks, soft disable and restart-safe storage. Scanning remains owned by M3 `TASK-011`.
- The first-run UI supports back/restart/edit, safe credential-status recovery, explicit-only Key/picker/preview actions, local-only/text-only/not-now degradation, two privacy confirmations, and a silent transition to RADIO with focus on Start.
