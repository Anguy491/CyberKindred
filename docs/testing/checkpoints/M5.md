## Completed scope

- `TASK-023` is `Done`: API-048 geocoding runs only after an explicit search, accepts a bounded query and returns Rust-owned in-memory candidates. API-049 saves coordinates only for an unexpired candidate explicitly selected by the user and uses revisioned persistence. Device location is absent.
- Forecast uses only the selected coordinates rounded to four decimals, the selected IANA timezone and fixed allowlisted weather parameters. Provider responses are bounded and validated; redirects, inconsistent timezone, non-finite values and malformed bodies fail closed. A 30-minute fresh cache may enter program Context; stale, missing, offline or failed weather is omitted and shown independently. Weather cache retention is seven days.
- `TASK-024` is `Done`: API-032–API-035, EVT-007, persistent weekly rules, transactional occurrence claims, IANA/DST calculation, 10/30/60-minute single snooze, 15-minute resume boundary and cancellable scheduler actor are integrated. Nonexistent local times advance to the first valid minute; ambiguous local times choose the earliest UTC occurrence.
- Native Windows notifications are silent and expose a fixed action allowlist for Start, Snooze 10/30/60, Dismiss and Open. Native callbacks reuse API-035 state transitions; only `Starting` invokes the radio starter, and API-024 consumes the start grant exactly once before planning, paid transport, speech or playback.
- Long sleep advances past missed occurrences instead of backfilling. Duplicate ticks, stale revisions, replayed actions and callbacks for deleted rules fail closed. Weak notification/authorization edges and actor `Drop` cancellation prevent strong cycles and orphaned scheduler tasks.
- Final security lifecycle review found and fixed a startup-order race: notification and program-start dependencies now bind before the scheduler actor begins evaluating due work.

- Early PowerShell/`rg` inspections used an unsupported glob, the old `docs/TRACEABILITY.md` path and later the nonexistent `src-tauri/src/weather.rs` path. These read-only errors were corrected to explicit paths and `src-tauri/src/weather/mod.rs`.
- Scheduler compile attempt 1/3 exposed an unformatted test module, an unexported `RadioFuture` and unused imports. Exports/imports and formatting were corrected; focused and full builds passed.

- Initial scheduler formatting checks found mechanical line wrapping. `cargo fmt` corrected it and the workspace formatting gate passed.
- Strict Clippy attempt 1/3 reported eight issues; attempt 2/3 retained one borrowed test-call issue; targeted fixes produced attempt 3/3 pass.
- Desktop E2E launch failed before application start because no matching `msedgedriver.exe` is installed. Per the user-only system prerequisite rule it was immediately classified `waiting for user`/`Not Run` and was not retried.
- An early `cargo audit` refresh encountered a transient yanked-registry status timeout while returning a non-failing result. The final exact-candidate audit refreshed cleanly, found no vulnerability and reported 18 allowed warnings.
- Several larger scheduler/native `apply_patch` hunks missed moving contexts. They produced no partial edits; smaller single-owner patches applied and were verified.
- The first final-scan launch used a guessed, invalid full SHA and was rejected before scan state existed. `git rev-parse` established the exact candidate.
- A scan of the preceding candidate was canceled after review exposed the startup binding race; the fix was committed and a new immutable scan became the sole final security result.
- Native-action formatting attempt 1/3 and 2/3 found only wrapping differences; attempt 3/3 passed after formatting.
- Native-action Clippy attempt 1/3 found a needless return, elidable lifetimes and a test guard held across `await`; the minimal fixes made attempt 2/3 pass.
- A superseded security draft submission omitted the required exclusion `pattern`; the corrected draft was accepted before that superseded scan was abandoned.
- Final security preflight progress synchronization was rejected three times: derived fields were supplied, the scan phase had already advanced, then backward phase transition was forbidden. Calls stopped at 3/3; the independent preflight and architecture results remain recorded in this checkpoint and final coverage, while the final scan itself completed successfully.
